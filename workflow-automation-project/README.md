# Workflow Automation Solution

![Workflow Automation Process]()

## Project Summary

Developed an end-to-end workflow automation solution that centralized program data and automated operational processes supporting invoicing, work orders, and RFP management across multiple customer programs.

The solution integrated data from iCare, Snowflake, Power BI, Power Automate, Excel, and Smartsheet to eliminate manual processes, improve data accuracy, and streamline business operations.

## Project Overview

Developed a workflow automation solution that transformed manually managed operational processes into an automated data pipeline.

Program data entered into iCare was loaded into Snowflake, creating a centralized data repository for reporting and analytics. Power BI dashboards were built to provide business visibility and operational reporting.

Power Automate workflows generated structured Excel files containing required business information and automatically placed them in designated folders. Smartsheet Data Shuttle then imported the files into targeted Smartsheets to support invoicing, work orders, and RFP processes across multiple programs.
